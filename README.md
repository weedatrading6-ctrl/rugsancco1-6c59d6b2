# Rugsan Brand Builder

Build a brand-new premium website from scratch for **RUGSAN CONSTRUCTION COMPANY**.

Do not ask for additional research or clarification. Use the content and implementation guidance below as the complete project brief.

## 1. Brand and content rules

Rugsan is a professional construction company focused on:

- Architecture Design
- Interior Design
- Civil Engineering
- Construction-related work

The brand should feel modern, architectural, functional, beautiful, durable, quality-focused, and future-oriented.

Do not invent:

- Projects
- Clients
- Testimonials
- Awards
- Certifications
- Statistics
- Dates
- Budgets
- Locations
- Project sizes
- Achievements
- Social accounts
- Unsupported claims

Do not create a testimonials or statistics section.

The following phrase must not appear anywhere:

`HAL-KU-DHIGGEENNA`

## 2. Languages

Support exactly three languages:

- Somali — default language
- English
- Arabic

Use visible language controls:

`SO / EN / AR`

Somali must load first on the initial visit. Save the selected language for future visits.

Update all visible content when the language changes, including navigation, headings, paragraphs, buttons, services, projects, founder content, contact content, footer, and metadata.

Arabic must use proper RTL layout with `dir="rtl"`.

Use natural professional Somali, English, and Arabic. Do not mix languages.

## 17. Motion

Use subtle, performant motion only:

- Hero fade and upward entrance
- Scroll reveal
- Image hover zoom
- Button hover transitions
- Active navigation transitions
- Mobile menu fade/slide
- Smooth internal scrolling
- Subtle CTA ambient motion

Use approximately:

- Image hover: 700ms
- Button transitions: 250–300ms
- Scroll reveal: 600–800ms
- Ambient CTA motion: 14–18 seconds

Do not use aggressive parallax or distracting effects.

Respect `prefers-reduced-motion`.
